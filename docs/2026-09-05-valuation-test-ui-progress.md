# 第一子系統簡易測試前端：目前進度與後續任務

更新日期：2026-09-05
工作分支：`feature/integrate-valuation-review`

## 這次要完成的流程

```text
估價製作
→ 第一次送審
→ Review 退回
→ 修改內容或補件
→ 重新產生正式報告
→ 再次送審
→ Review  重新檢查
```

這是一個開發測試用的簡易前端，不是正式上線版。

## 目前完成的功能

### 1. 查估端可以看到 Review 狀態

- 可以看到案件目前是製作中、審查中、退回補正或審查完成。
- 可以看到 Review 要求修改的原因、期限與缺少的資料。
- 不會把密碼、登入憑證、儲存位置或 Review 內部資料顯示在畫面上。

狀態：已完成並通過獨立審查。

### 2. 重新送審會自動接回原本的 Review 案件

- 補正後會建立新的送審版本，不覆蓋第一次送審內容。
- 重新送審時，不需要人工輸入 Review ID、補正單 ID 或文件 ID。
- 新版本送出與補正回覆會一起成功或一起失敗，避免兩邊資料不同步。

狀態：已完成並通過獨立審查。

### 3. 測試帳號工具

- 可建立開發環境用的 `valuation_demo` 查估人員帳號。
- 有 `seed`、`status`、`reset` 指令。
- 正式環境不會開放這個工具。

狀態：已完成並通過獨立審查。

### 4. 簡易測試頁面

- 網址為 `/api/v1/valuation/test-ui`。
- 只有開發環境可以開啟。
- 使用中文欄位，不需要操作 Swagger 或手動輸入 JSON。

狀態：已完成並通過獨立審查。

### 5. 第一次送審流程

目前頁面已支援：

- 登入。
- 建立案件與上傳多個檔案。
- 查看 OCR／AI 擷取候選內容。
- 逐項確認、拒絕或修正候選內容。
- 執行正式計算、檢核與產生正式 PDF。
- 下載正式 PDF。
- 第一次送交 Review。
- 送審後鎖定編輯，避免誤改。

驗證結果：

- 前端行為測試：25 項通過。
- 隔離 Docker 後端測試：26 項通過，測試資料已清除。
- Luna Max 獨立審查：通過。

狀態：已完成。

### 6. Review 退回後的修改／補件與重新送審

目前已寫好：

- 分開顯示「內容需要修改」與「需要補充資料」。
- Review 的要求只能閱讀，查估端不能改 Review 的疑點或退回通知。
- 退回後可修改查估資料、上傳新版文件並重新擷取。
- 可建立新版正式報告並重新送審。
- 第一次送審紀錄會保留。
- 重新送審後會顯示「已重新送審」。

目前驗證：

- 前端行為測試：31 項通過。
- 程式基本檢查：通過。
- 已建立實作 commit：`58a08db`。

狀態：功能已寫好，但尚未完成獨立審查與隔離 Docker 測試，所以目前不能算正式驗收完成。
