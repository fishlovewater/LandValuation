# 如何開啟登入頁面

這份說明只適用於本機黑客松 Demo，不適用於正式環境或 AWS。

## 最快開啟方式

如果後端與前端都已經啟動，直接用 Chrome 開啟：

<http://127.0.0.1:5173>

如果無法開啟，請依照下面步驟重新啟動。

## 第一次啟動

### 1. 開啟 Docker Desktop

先確認 Docker Desktop 已啟動完成。

### 2. 啟動後端服務

開啟 PowerShell，進入專案的 `frontend-demo` 工作目錄：

```powershell
cd C:\Users\User\project\LandValuationAssistant\.worktrees\frontend-demo
```

啟動 PostgreSQL、MinIO、資料庫更新與 API：

```powershell
$compose = @(
  '-p', 'landvaluation-persistent-demo',
  '-f', 'docker-compose.yml',
  '-f', 'docker-compose.demo.yml',
  '--env-file', '.env.example'
)

docker compose @compose build migrate api
docker compose @compose up -d db db-role-init migrate minio minio-init api
$ready = $false
$lastStatus = $null
for ($attempt = 1; $attempt -le 30; $attempt++) {
  try {
    $response = Invoke-WebRequest -UseBasicParsing http://127.0.0.1:18000/health/ready
    $lastStatus = $response.StatusCode
    if ($response.StatusCode -eq 200) {
      $ready = $true
      break
    }
  } catch {
    $lastStatus = $_.Exception.Message
  }

  if ($attempt -lt 30) {
    Start-Sleep -Seconds 2
  }
}
if (-not $ready) {
  throw "後端在 30 次檢查後仍未就緒（最近結果：$lastStatus）。請確認 Docker Desktop 與後端服務是否正常。"
}
Write-Output '後端已準備完成（HTTP 200）。'
```

看到狀態碼 `200`，代表後端已經準備完成。

### 3. 建立 Demo 資料

在同一個 PowerShell 視窗執行：

```powershell
docker compose @compose exec -T api python -m app.demo seed | Out-Null
docker compose @compose exec -T api python -m app.demo status
```

`status` 顯示 `"ready": true` 就可以繼續。

> 不需要解析 `seed` 的輸出，也不需要設定 API key。

### 4. 啟動前端

另外開啟一個 PowerShell 視窗，執行：

```powershell
cd C:\Users\User\project\LandValuationAssistant\.worktrees\frontend-demo\frontend
$env:VITE_API_BASE_URL = '/api/v1'
npm.cmd install
npm.cmd run dev -- --host 127.0.0.1
```

這個 PowerShell 視窗要保持開啟。

### 5. 開啟登入頁面

用 Chrome 開啟：

<http://127.0.0.1:5173>

## Demo 登入帳號

三組帳號的密碼都是 `Demo1234!`。

| 用途 | 帳號 | 可以使用的功能 |
|---|---|---|
| 估價人員 | `valuation_demo` | 估價作業、智能助理、案件歷程 |
| 審查人員 | `review_demo` | 審查工作台、案件歷程 |
| 查詢人員 | `inspector_demo` | 案件歷程 |

這些固定帳密只能用於本機開發 Demo，不能用於正式環境或 AWS。

## 常見問題

### 顯示「目前無法連線至服務」

先確認後端是否正常：

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:18000/health/ready
```

如果不是狀態碼 `200`，請確認 Docker Desktop 與後端服務是否已啟動。

### Chrome 顯示 CORS 錯誤

在前端 PowerShell 按 `Ctrl + C` 停止前端，再重新執行：

```powershell
$env:VITE_API_BASE_URL = '/api/v1'
npm.cmd run dev -- --host 127.0.0.1
```

回到 Chrome 按 `Ctrl + F5` 重新整理。

### 無法開啟 5173 網頁

確認執行前端的 PowerShell 視窗仍保持開啟，而且畫面顯示：

```text
Local: http://127.0.0.1:5173/
```

## 暫時停止前端

在執行前端的 PowerShell 視窗按 `Ctrl + C`。

這只會停止網頁，不會刪除 PostgreSQL、MinIO 或 Demo 資料。
