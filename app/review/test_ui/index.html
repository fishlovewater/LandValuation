尚未建立測試狀態
STEP 01

連線與登入

先在終端執行 seed，將輸出的一次性密碼貼入。密碼不會保存在此頁。

docker exec land_valuation_api python -m app.review.demo seed
STEP 02

案件與完整性

貼上 seed 輸出的 case_id，先建立 Review case，再做完整性檢查。

STEP 03

執行、疑點與風險

Run 是同步 API；成功應為 HTTP 200，且 run_status 為 COMPLETED。

STEP 04

人工決策與修正版複查

完成退回決策與 PREPROCESSING 後，在終端建立 v2，再回來做完整性檢查與 rerun。

docker exec land_valuation_api python -m app.review.demo revise
STEP 05

JSON 與 PDF 報告

PDF 先由 POST 產生並保存 MinIO metadata，再由 download endpoint 取得內容。

測試結束後清理：docker exec land_valuation_api python -m app.review.demo reset
